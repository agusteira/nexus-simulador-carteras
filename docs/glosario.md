# Glosario

Definiciones cotidianas para leer las pantallas y documentos de NEXUS. No son recomendaciones para operar.

| Término | En palabras simples |
| --- | --- |
| Acción | Una parte de la propiedad de una empresa. Su precio puede subir o bajar. |
| Fondo, FCI y cuotaparte | Un fondo reúne aportes de varias personas para invertirlos según reglas del fondo. Una cuotaparte representa una porción del fondo; su valor puede cambiar. |
| Renta fija | Instrumentos que suelen tener pagos o condiciones definidos, como ciertos bonos. “Fija” no quiere decir que su precio o resultado estén garantizados ni que no haya riesgo. |
| Renta variable | Acciones y otros instrumentos cuyo valor cambia con el mercado. |
| Inflación, CER y UVA | La inflación es el aumento general de precios. CER es un coeficiente y UVA una unidad; ambos se actualizan con referencias vinculadas a índices de precios. Un instrumento asociado puede variar y no garantiza conservar poder de compra. |
| Dólar-linked | Instrumento en pesos cuyo valor busca seguir una referencia del dólar. No equivale a tener dólares ni garantiza el mismo resultado. |
| Liquidez y rescate | Liquidez es la facilidad para disponer del dinero. Rescate es pedir que un fondo devuelva el valor de las cuotapartes; el plazo depende de sus condiciones. |
| Día hábil, T+0 y T+1 | Día hábil es un día operativo del mercado. T+0 suele indicar que la entrega se realiza el mismo día hábil; T+1, el día hábil siguiente, según las condiciones del producto y del intermediario. |
| Moneda de cotización y de fondeo | La moneda de cotización es aquella en la que se muestra el precio. La moneda de fondeo es la que acepta el intermediario para pagar; pueden ser distintas. |
| CEDEAR y ETF | Un CEDEAR representa en Argentina un valor negociado en otro mercado, según su programa. Un ETF es un fondo que cotiza en un mercado; no todo ETF es un activo local ni queda incluido en esta simulación. |
| Comisión y gasto anual | Una comisión puede cobrarse por una operación o servicio. El gasto anual de un fondo es un porcentaje publicado para el fondo; no es necesariamente el costo total de una orden ni un monto en pesos. |
| Patrimonio | Es el valor de los activos de una clase o fondo informado por la fuente. Un patrimonio grande no demuestra que sea seguro ni que se pueda operar fácilmente. |
| Diversificación | Repartir una inversión entre distintos activos puede reducir algunas concentraciones, pero no elimina el riesgo ni garantiza un resultado. |
